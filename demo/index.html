Are You Asking the Right Questions?

An independent check for questions written by AI. Machines now write prediction-market questions at scale — a question people bet on, where the answer is YES or NO. Nobody independent was checking whether those questions were fair, clear, and settleable. This page shows the check, run on real questions, with real numbers. Nothing here is invented.

What was built during this event — and what was not

Built during this event (Oct 26 – Nov 4, 2026): the 48-question generation set, the checklist scorer, the answer-generation run, the engine-run integration on those answers, the rewrite loop, and this demo page.

Prior work — declared, never presented as event work: the audit engine core (the Bayesian model and the quantum-style order module), its 145 tests, and the Oct 20 Octagon audit of 100 real AI-written questions. The engine core stays private; this public page shows only what it measured, not the code itself. Full disclosure: github.com/Lovejoyhealth/asking-the-right-questions (PRIOR_WORK.md).

The one-line difference: SurveyMonkey-style tools check the questions. We check the answers — what the questions did to the people (here, one AI forecaster) answering them.

How the check works, in plain words

  1. Muse Spark writes the questions. Spark, using the Meta Model API, wrote 48 prediction-market questions: 12 topics, 4 questions each.
  2. The checklist scorer grades the wording. A plain, fixed program (no AI) reads each question and flags problems it can see in the text: a deadline already in the past, no source named to settle the answer, or a specific number a human must verify.
  3. Spark answers the questions many times, in shuffled order. One plain Spark forecaster answered each topic's 4 questions 25 times, with the order shuffled every time: 300 calls, 1,200 probabilities (a number from 0 to 100 for how likely YES is).
  4. The audit engine measures what the order did to the answers. If a question scores differently just because it was asked first instead of later, the list itself is pushing the result. Every effect is compared against shuffled data, so a reading can be judged against what pure chance produces.
  5. Flagged questions get rewritten and re-scored. Spark rewrites only the flagged problems; the scorer checks the rewrite. Before and after, side by side, is the demo moment.

Step 1 — The 48 questions: what the checklist found

31 of 48 questions flagged. The counts below add up to more than 31 because some questions carry two flags.

Flag, in plain wordsCountWhat it means
PAST_DATE — deadline already passed5The question's deadline was already in the past on Oct 26, 2026, so it can no longer be settled in the future.
NO_SOURCE_CUE — no settling source named9The wording names no source or authority that decides the answer (no "according to…", official body, or result cue).

Wording, honestly: no loaded-wording flag fired on this set (0 LOADED_CUE flags, and no double-barreled flags). The 31 flags above are all about whether a question can be settled cleanly — not about one-sided wording. 17 of the 48 questions carried no flag at all.

The five dead-date questions

These five questions set deadlines that had already passed when they were written on Oct 26, 2026. A question that cannot be settled in the future is not a usable market question.

  1. Q10 (the US economy and jobs) — "Will US nonfarm payroll employment exceed 160 million by July 31, 2026 according to the Bureau of Labor Statistics?"
  2. Q14 (interest rates and the Federal Reserve) — "Will the Federal Reserve announce at least one interest rate cut before June 30, 2026?"
  3. Q33 (pro sports championships) — "Will the Kansas City Chiefs win Super Bowl LX by February 8, 2026?"
  4. Q35 (pro sports championships) — "Will the Boston Celtics win the 2026 NBA Championship by June 30, 2026?"
  5. Q43 (energy and gas prices) — "Will Brent crude oil futures settle above 100 dollars per barrel on September 30, 2026 according to ICE?"

Step 4 — The engine run: what the answers did

No broad order effect. Across all 48 questions, the average size of the first-vs-later difference was 2.91 points (on a 0–100 scale). 43 questions showed no effect, 1 was flagged, and 4 were suggestive. No question pair cleared the chance bar on the pair-order check (0 of 72 pairs).

How to read "effect": the position effect is the average probability when a question was asked first, minus the average when it was asked later. A value of −12 means "12 points lower when asked first." The flag rule was fixed before the run: flagged needs a shuffle-test p-value below 0.05 (shuffling rarely produces a difference that big) and an effect of at least 10 points.

The one flagged question: Q32

"Will NASA confirm discovery of a new potentially habitable exoplanet by September 30, 2027?"
Average overall: 72.0. Asked first: 63.29 (7 runs). Asked later: 75.39. Effect: −12.1 points, shuffle p = 0.0045.

Read honestly: with 48 questions tested, about 2 to 3 false alarms are expected from pure chance alone. Q32 is a lead worth re-testing with more runs, not a proven flaw — only 7 runs had it first, so one or two unusual answers can move the average a lot.

Suggestive, but too small to flag

  • Q08 — effect +2.11 points, p = 0.0185.
  • Q09 — effect −8.6 points, p = 0.0055.
  • Q30 — effect −8.01 points, p = 0.015.
  • Q31 — effect −2.68 points, p = 0.043.

Answers that moved together

Some pairs' probabilities moved together across runs far more than shuffled data does. That is not an order effect — it says the forecaster's mood on one question tracked its mood on the other inside the same call. Strongest pairs: Q01/Q04 (correlation 0.847), Q09/Q11 (0.81), Q10/Q11 (0.724), Q09/Q10 (0.674), Q10/Q12 (0.69), Q47/Q48 (0.59), Q09/Q12 (0.532), Q11/Q12 (0.505).

What ran — and what did not — stated plainly

  • Ran: the permutation shuffle tests and the model-free order statistics from the prior engine's code, plus this run's own first-vs-later shuffle test (2,000 shuffles per question).
  • Second pass (Oct 27) — the full engine ran: the Pyro Bayesian track (coupling ranges for all 72 pairs; 9 of the 10 strongest classical couplings confirmed; Q32's Bayesian range excludes zero) and the PennyLane circuit check (12 of 12 agreements at machine precision), run in the engine's own Python environment — the first pass used the wrong Python. The fitted quantum-style model also ran and is reported plainly: it overstates order effects on this data, so nothing on this page rests on it.
  • Limits: one AI forecaster, not humans. First-position samples are small (2–12 runs per question). Pair checks split probabilities at 50, so 49 and 51 land on opposite sides though they are nearly the same belief. 48 tests invite chance hits. And a question can be clean in the answer run and still be badly worded, or vice versa — the checklist and the answer run are separate layers.
